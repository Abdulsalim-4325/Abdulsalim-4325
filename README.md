## 01 / Engineering philosophy

I am a Computer Science Engineering student focused on backend infrastructure, distributed systems, and security-conscious software design.

My interests lie in the engineering problems beneath the interface: reliable message processing, asynchronous workloads, API design, data integrity, fault recovery, and systems that behave predictably under pressure.

I care about more than making software work. I want to understand **why it works, where it fails, and how to measure the difference.**

<table>
<tr>
<td width="50%" valign="top">

**01 — Reliability**

Idempotency, retries, exponential backoff, failure recovery, and predictable processing semantics.

</td>
<td width="50%" valign="top">

**02 — Architecture**

APIs, asynchronous workers, queues, data pipelines, caching, and service boundaries.

</td>
</tr>
<tr>
<td width="50%" valign="top">

**03 — Security**

Data minimization, privacy-aware systems, authentication, and secure application design.

</td>
