## About Me

I'm a Computer Science Engineering student focused on backend engineering, distributed systems, and security-conscious software architecture.

I enjoy working on the engineering beneath the interface: asynchronous processing, reliable APIs, data pipelines, fault recovery, and privacy-aware systems.

My goal is to build software that doesn't merely work under ideal conditions, but behaves predictably when things go wrong.

**Current focus:** Backend infrastructure · System design · Data structures and algorithms · Security research
